# BOOKING WISATA KE GUNUNG BROMO

Aplikasi pemesanan tempat duduk untuk kegiatan
wisata Gunung Bromo.

## Teknologi
- Google Apps Script
- Google Sheets
- HTML
- CSS
- JavaScript

## Struktur File
- Code.gs: Logika server dan penyimpanan booking.
- Index.html: Tampilan aplikasi.

## Database
Menggunakan Google Sheets dengan dua sheet:

1. DATA_GURU
2. BOOKING

## Fitur
- Pemilihan nama guru/karyawan.
- Penambahan peserta.
- Maksimal 5 peserta tambahan.
- Pencegahan booking ganda berdasarkan ID guru.
- Penyimpanan data booking.
- Tampilan bukti booking.

## Deployment
Aplikasi dijalankan melalui Google Apps Script.

GitHub digunakan sebagai tempat penyimpanan
kode sumber dan pengelolaan versi.
